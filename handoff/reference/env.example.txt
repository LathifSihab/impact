# Environment variables for the IMPACT site.
#
# Copy to .env for local work. Never commit .env — it is gitignored.
# In Netlify these live under Site configuration → Environment variables, scoped
# per deploy context so staging and production can differ.
#
# The principle: nothing that identifies an account is hardcoded. Handover is
# then a credential swap in a UI, not a code change and a redeploy.
#
# Astro exposes only PUBLIC_-prefixed variables to the browser. Everything else
# stays server-side. Same convention applies to the Python tools.

# ---- site -------------------------------------------------------------------
# The single value that must not be wrong: a canonical pointing at a domain the
# site is not served from keeps the real domain out of the index.
# NOTE: the static site is built locally and committed, so this applies when
# *we* run tools/build.py — it is not read at deploy time until the site has a
# real build step. Set it when building for staging:
#   PUBLIC_SITE_URL=https://demo-impact-c399e3.netlify.app python tools/build.py
PUBLIC_SITE_URL=
PUBLIC_ENV=
